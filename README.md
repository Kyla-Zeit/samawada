# Samawada

A modern nonprofit website concept focused on expanding access to clean water in East Africa.  
Built for clarity, speed, and easy content updates.

👉 **[View Live Site](https://kyla-zeit.github.io/samawada/)**

---

## 🚀 Features
- Responsive layout with accessible navigation and sections
- Clear information architecture (About, Projects, Events, Community Voices, Donate, Contact)
- Impact highlights and project cards for quick scanning
- Testimonials/Community Voices section with quotes and attributions
- Donation UI (amount presets, monthly toggle, donor info fields)
- Reusable components and utility classes for consistent spacing/typography
- Lightweight, fast-loading front end suitable for GitHub Pages
- SEO-friendly metadata structure and social share preview support
- Keyboard-focus states and semantic HTML for better accessibility

---

## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** (utility classes + custom components)
- **TypeScript** for typed, modular UI logic (compiled to JavaScript)
- **GitHub Pages** for hosting and deployment
